# Nom de l'app : recherche d'antériorités (25.11.2026)

Recherche web seulement : aucune inscription, aucun achat, aucune donnée personnelle transmise.
Méthode :
- domaines : interrogation DNS (`dig`) pour .ch / .com / .app / .fr, confirmée pour les finalistes par les registres RDAP officiels (Verisign pour .com, SWITCH pour .ch ; réponse 404 = non enregistré) ;
- applications : API de recherche de l'App Store (Suisse et France) et page de recherche de Google Play (Suisse, en français) ;
- web et réseaux sociaux : recherche web sur le nom exact ;
- marques : TMview (EUIPO) refuse les requêtes automatiques ; Swissreg et INPI demandent un navigateur. **Ces registres restent donc à consulter à la main** avant tout choix définitif (swissreg.ch, euipo.europa.eu/eSearch, data.inpi.fr, classes 9, 41 et 42).

« Libre » signifie : pas enregistré au 25.11, ou aucune trace trouvée. Ce n'est pas une garantie.

## 1. « Mathélo » comme nom d'app

**Conflit gênant : à écarter comme nom d'app.**

- **mathelo.fr** est actif : « Mathelo – Spécialiste du Soutien en Maths ». Il est édité par le « Groupe Mathelo Education » : cours particuliers de maths à domicile en Île-de-France, stages, cours en ligne gratuits avec exercices corrigés. Son public est le collège, le lycée et le supérieur, avec les parents. C'est le **même secteur, la même langue et le même public**. On n'a pas trouvé de marque déposée visible, mais l'usage antérieur suffit pour risquer une confusion, et peut-être une opposition si une marque existe.
- **mathelo.com** est enregistré depuis 2017 et **à vendre** chez HugeDomains (revendeur, prix en général de 1'000 à 3'000 USD).
- **mathelo.app** est enregistré (DNS Google), sans page.
- **mathelo.ch** est libre.
- Aucune app « Mathelo » sur l'App Store ni sur Google Play, et aucun compte social trouvé par recherche.
- Connotations : le jeu de mots math + Elo est compris des joueurs d'échecs et de jeux vidéo, et neutre ailleurs. Pas de sens gênant trouvé dans d'autres langues.

**Conclusion** : garder « Mathélo » **pour le score**, où il est déjà installé. À cet usage interne, le risque de confusion est faible. Le nom de l'app doit être autre chose.

Si l'utilisateur tenait malgré tout à Mathélo comme nom d'app, il faudrait renommer le score. Pistes : « ta cote », « niveau », « Élo maths », « indice ». Toutes sont moins parlantes que Mathélo. Ce n'est pas recommandé.

Réseaux sociaux : Instagram et TikTok bloquent les vérifications automatiques. Aucun compte homonyme n'est apparu dans les recherches web pour les trois noms recommandés. Il faut vérifier à la main les identifiants @quotimaths, @mathfil et @mathpli avant de choisir, et les réserver si le nom est retenu.

Connotations dans d'autres langues : rien de gênant trouvé pour les trois recommandés. « Fil » et « pli » n'ont pas de sens grossier en allemand, en italien, en anglais ni en espagnol. En allemand, « Quoti- » rappelle « Quote » (taux, quota), ce qui est neutre.

## 3. Recommandation

1. **Mathfil**, sous-titre « 5 minutes de maths par jour ». C'est le plus court et le plus facile à taper, et il évoque la continuité (« garder le fil ») et l'accompagnement. Tous les domaines sont libres. Le score reste « Mathélo », sans confusion : un nom pour l'app, un autre pour le score.
2. **Quotimaths**. C'est le plus immédiatement compris (maths + quotidien), par les élèves comme par les parents. Tous les domaines sont libres. Comme le nom est descriptif, la marque est moins facile à protéger, mais il y a peu de risque de conflit.
3. **Mathpli** (« prendre le pli »). Il est distinctif, donc la meilleure base pour une marque. Tous les domaines sont libres, mais le sens demande un mot d'explication.

Avant de choisir :
- consulter à la main Swissreg, EUIPO eSearch et l'INPI (classes 9, 41, 42) ;
- vérifier les identifiants Instagram et TikTok ;
- si le nom est retenu, réserver au moins le .ch et le .com (et le .app pour une PWA). Les noms libres et courts partent vite.

## Deuxième tour (25.11.2026) : 20 noms hors « math + mot »

Mêmes vérifications que pour le premier tour :
- domaines .ch / .com / .app / .fr par DNS ;
- App Store (France) par son API de recherche, Google Play par sa page de recherche ;
- recherche web sur le nom exact ;
- comptes sociaux par recherche web seulement.

Les mots français courants (Jalon, Sablier, Tandem…) sont pris dans **toutes** les extensions ou presque. Pour ces noms, j'ai donc aussi vérifié la variante `<nom>maths` (ex. jalonmaths.ch), utilisable comme domaine pendant que l'app garde le nom court.
